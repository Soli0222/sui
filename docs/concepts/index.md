# ドメイン規則

残高の数え方と、将来の収支をどう組み立てるかの規則をまとめる。

# Concepts

* [可処分残高とオフセット](disposable-balance.md) - 実残高からオフセットを引いた額を予測の基準にする規則と、口座ごとの警告レベル。
* [残高照合と調整取引](balance-reconciliation.md) - 実残高とのずれを adjustment 取引として残し、過去の履歴を書き換えない仕組み。
* [予測イベント](forecast-event.md) - 予測の生成元、決定的な ID、並び順、期日超過と手動確定。
* [クレジットカード請求の仮定値と実績](credit-card-billing.md) - 想定額と実績額の切り替え、翌月以降に効く安全弁、引き落とし日の決め方。
* [ローン返済の再計算](loan-repayment.md) - 残額を残回数で割り直す方式と、確定済み返済の織り込み。
* [サブスク台帳](subscription-ledger.md) - サブスクを残高予測に統合しない理由と、月別と年間の集計規則。
* [給与台帳](salary-ledger.md) - 給与明細を残高予測に統合せず、額面・控除内訳を記録する理由と導出値の定義。
* [割り勘と精算](split-and-settlement.md) - 立替の分割、端数の寄せ方、回収の記録と充当の検証。
* [スケジュールと営業日シフト](schedule-and-business-day.md) - 月次と週次の発生日の展開と、土日祝に当たった日付の寄せ方。
* [複数通貨と JPY 換算](multi-currency.md) - 対応通貨、換算のタイミング、為替レートの更新と通貨をまたぐ操作の制限。
